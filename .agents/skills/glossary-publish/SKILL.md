name: glossary-publish
description: Сборка, независимая сверка и публикация статического глоссария книжных выставок в GitHub Pages.
---

Собери из извлечённых материалов отдельные URL выставок, введение, заключение и страницы букв. Свяжи каждую выставку с разделом. Пиши ссылки на ресурсы относительно документа, а canonical и sitemap — от действительного адреса Pages с префиксом проекта.

Сверь реестр и выходные страницы поштучно. Сравни нормализованный текст, значимые элементы и порядок иллюстраций, проверь подписи, существование целевых файлов с точным регистром и внутренние якоря. Повторная сборка должна давать те же файлы. Объясни количественные расхождения в отчёте.

До публикации проверь текущий источник Pages и пользовательский домен. Проверь реальные изображения после получения Git LFS. Workflow должен проверять и загружать в Pages только site/. Сохраняй существующий домен. После запуска проверь по HTTPS главную, буквы начала, середины и конца, выставки, разные изображения и ответ 404 для неизвестного пути. В отчёте укажи дату, запуск, проверенные URL и оставшиеся ограничения.
