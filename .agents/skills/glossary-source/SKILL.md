Начни с алфавитного указателя glossary.ufacsdb.ru. Открой введение и заключение, каждую представленную букву и все продолжения. Различай страницу Joomla и самостоятельную выставку внутри неё. Сохраняй адрес, раздел, заголовок, содержательную разметку и порядок в проверяемом реестре вне site/. Повторно используй сохранённые ответы.

Проверяй границы статьи по заголовкам и структуре реальной страницы. Сохраняй примеры, повторяющиеся абзацы, списки, подписи, таблицы и ссылки. Для галерей учитывай и миниатюру, и адрес полного изображения. Идентичность материалов на разных адресах подтверждай текстом.

Сопоставляй относительный адрес изображения с путём внутри site/, декодируя URL и проверяя регистр. Для Git LFS сверь реальные байты с oid и размером указателя. Используй только файлы из репозитория. При неоднозначности перечисли кандидатов и исходный URL в отчёте. Передай сборщику записи вместе с нерешёнными случаями.
